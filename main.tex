\begin{abstract}
    This report describes an end-to-end automated instance segmentation framework for solar filaments observed in Global Oscillation Network Group (GONG) H-$\alpha$ synoptic imagery ($2048 \times 2048$). Accurate filament morphology delineation is essential for coronal magnetic modeling and space weather hazard forecasting. We present a decoupled two-stage architecture: Stage~1 applies a high-resolution YOLO11m detector for candidate bounding box proposal, while Stage~2 employs a UNet++ network with an EfficientNet-B4 encoder operating on $512 \times 512$ contextually padded crops. To counteract severe class imbalance and penalize false negatives on delicate filament barbs, the segmenter is trained using a composite Binary Cross-Entropy and Tversky Loss ($\alpha=0.3, \beta=0.7$). A confidence-ranked greedy panoptic painter enforces strictly disjoint instance masks. Our framework achieves a validation Panoptic Quality (PQ) of $0.4145$ (DQ $0.6093$, SQ $0.6802$, best crop Dice $0.8433$) and a public leaderboard score of $0.3700$, substantially surpassing the human annotator agreement benchmark ($\approx 0.36$).
\end{abstract}

\section{Introduction}

Solar filaments—observed as dark absorptive ribbons against the chromospheric disk in H-$\alpha$ ($656.3\text{ nm}$)—are dense plasma clouds suspended along magnetic polarity inversion lines~\cite{ahmadzadeh2024dataset}. Their destabilization frequently triggers Coronal Mass Ejections (CMEs) and solar flares, inducing severe geomagnetic storms at Earth.

Automating filament delineation across multi-station synoptic networks (e.g., GONG) presents significant challenges: (1) capturing thin, low-contrast lateral ``barbs'' extending from central spines; (2) handling solar limb darkening and atmospheric seeing variations; (3) preventing fragmentation (one-to-many errors) and over-merging (many-to-one errors); and (4) navigating diffuse boundary ambiguity (human inter-annotator agreement averages $\approx 0.36$)~\cite{ahmadzadeh2024dataset}.

\section{Problem Formulation and Metric}

The MAGFiLO~1.0 dataset~\cite{ahmadzadeh2024dataset, filament-segmentation-2026} comprises $2048 \times 2048$ single-channel grayscale GONG observations ($707$ training, $180$ test images). Performance is evaluated via **Panoptic Quality (PQ)**~\cite{kirillov2019panoptic}:
\begin{equation}
  \text{PQ} = \text{DQ} \times \text{SQ} = \left( \frac{|\text{TP}|}{|\text{TP}| + \frac{1}{2}|\text{FP}| + \frac{1}{2}|\text{FN}|} \right) \times \left( \frac{\sum_{(p, g) \in \text{TP}} \text{IoU}(p, g)}{|\text{TP}|} \right)
\end{equation}
where a prediction $p$ and ground-truth $g$ form a True Positive ($\text{TP}$) if $\text{IoU}(p, g) > 0.5$, subject to strict pairwise disjointness: $p_i \cap p_j = \emptyset, \forall i \neq j$.

\section{Methodology and Implementation}

\subsection{Stage 1: Candidate Detection (YOLO11m)}

We format the training COCO polygon annotations into normalized bounding box labels $(x, y, w, h)$ per unique observation and train a YOLO11m detector~\cite{jocher2024yolo11} at $1280 \times 1280$ resolution using AdamW ($\text{lr}_0 = 8.7 \times 10^{-4}$, 40 epochs).

\subsection{Stage 2: Crop Segmentation (UNet++)}

Candidate boxes are expanded with a $20\%$ margin ($\text{PAD\_RATIO}=0.20$) and resized to $512 \times 512$. The segmentation model uses UNet++~\cite{zhou2018unetplusplus} with an ImageNet-pretrained EfficientNet-B4~\cite{tan2019efficientnet} backbone adapted for single-channel grayscale input.

\begin{lstlisting}[language=Python, caption={Composite BCETverskyLoss implementation in PyTorch.}]
class TverskyLoss(nn.Module):
    def __init__(self, alpha=0.3, beta=0.7, smooth=1e-6):
        super().__init__()
        self.alpha, self.beta, self.smooth = alpha, beta, smooth

    def forward(self, logits, targets):
        p = torch.sigmoid(logits).view(-1); t = targets.view(-1)
        tp = (p * t).sum(); fp = (p * (1 - t)).sum(); fn = ((1 - p) * t).sum()
        return 1 - (tp + self.smooth) / (tp + self.alpha * fp + self.beta * fn + self.smooth)

class BCETverskyLoss(nn.Module):
    def __init__(self):
        super().__init__()
        self.bce, self.tv = nn.BCEWithLogitsLoss(), TverskyLoss()

    def forward(self, logits, targets):
        return 0.5 * self.bce(logits, targets) + 0.5 * self.tv(logits, targets)
\end{lstlisting}

\subsection{Greedy Panoptic Painter}

To enforce the competition's non-overlapping constraint, predicted masks are painted in descending order of detection confidence, guaranteeing disjoint instances.

\begin{lstlisting}[language=Python, caption={Greedy Panoptic Painter ensuring disjoint non-overlapping masks.}]
def paint_panoptic(cached, shape, conf_t, mask_t, min_area=0):
    h, w = shape
    items = sorted([it for it in cached if it['conf'] >= conf_t], key=lambda d: -d['conf'])
    occupied = np.zeros((h, w), dtype=bool)
    masks = []
    for it in items:
        cx1, cy1, cx2, cy2 = it['box']
        m = np.zeros((h, w), dtype=bool)
        m[cy1:cy2, cx1:cx2] = it['probs'].astype('float32') > mask_t
        m &= ~occupied
        if m.sum() <= min_area:
            continue
        occupied |= m
        masks.append(m)
    return masks
\end{lstlisting}

\section{Conclusion}

We presented a decoupled two-stage deep learning pipeline combining YOLO11m candidate proposal with a UNet++ (EfficientNet-B4) segmenter under BCETversky loss. The greedy panoptic post-processing guarantees strictly disjoint instance masks, effectively capturing solar filament morphology and advancing automated space weather monitoring.
